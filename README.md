# Приложение для получения информации о работодателях и вакансиях с платформы hh.ru.

## Описание:

Программа получает данные о работодателях и их вакансиях с сайта hh.ru, сохраняет их в JSON-файлы и проектирует таблицы в БД PostgreSQL для хранения полученных данных.

## Установка:

Клонируйте репозиторий:
```
https://github.com/hristyaa/HeadHunter_db.git
```
Скопируйте файл `.env.example` и переименуйте его в `.env`
Откройте `.env` и заполните ваши данные для подключения к базе данных.

Установите необходимые зависимости:
- c помощью Poetry:
```
poetry add psycopg2 
poetry add pytest 
```
- с помощью pip:
```
pip install -r requirements.txt
pip install python-dotenv 
pip install types-psycopg2
pip install types-requests  
```

## Запуск:

```
python main.py
```

## Функциональные возможности:
Функциональный код разбит на модули: модуль для взаимодействия с API, модуль для создания базы данных, модуль для взаимодействия с базой данных.
1. **Модуль для взаимодействия с API - hh_api.py**.
Реализованы следующие методы:
1. [x] **метод get_company** отвечает за получение данных о топ-10 компаниях с наибольшим количеством вакансий (по умолчанию в Чите)
и сохранение данных в JSON-файл "company.json" (по умолчанию);
2. [x] **метод get_employers_id** отвечает за получение списка employers_id (id работодателей);
3. [x] **метод insert_employers_from_json** отвечает за загрузку данных по API-запросу о работодателях в таблицу employers;
4. [x] **метод get_vacancy** отвечает за получение данных о вакансиях топ-10 работодателей и сохранение данных в JSON-файл "vacancy.json" (по умолчанию);
5. [x] **метод insert_vacancies_from_json** отвечает за загрузку данных по API-запросу о вакансиях в таблицу vacancies.
Все данные, полученные по API-запросу (о работодателях и вакансиях) сохраняются в директорию data, которая создается в корне проекта автоматически (при отсутствии).  
2. **Модуль для создания базы данных - hh_database.py**.
Реализованы следующие методы:
1. [x] **метод create_database** создает базу данных PostgreSQL;
2. [x] **метод create_tables** создает SQL-таблицы "employers" и "vacancies", таблица организаций заполняется 10 записями о компаниях для сбора вакансий, таблица вакансий заполняется записями о вакансиях компаний;
3. [x] **метод clear_table** очищает данные в таблицы.
3. **Модуль для с базой данных - db_manager.py**. 
- Создан **_абстрактный класс DBManagerABC_** для работы с базой данных PostgreSQL, в котором осуществляется инициализация класса, установка и закрытие соединения с базой данных:
2. [x] **метод connect** отвечает за установку соединения с базой данных PostgreSQL;
3. [x] **метод close** отвечает за закрытие соединения;
4. [x] **абстрактный метод get_all_from_table** (обязательный для реализации в дочерних классах) отвечает за получение всех данных из указанной таблицы. 
- Создан **_класс DBManager_**, который является дочерним классом DBManagerABC, для работы с базой данных (таблицами employers и vacancies).
В классе реализованы следующие методы:
5. [x] **метод get_all_from_table** (обязательный для реализации) отвечает за получение всех данных из указанной таблицы;
6. [x] **метод get_companies_and_vacancies_count** отвечает за получения списка всех компаний и количества вакансий у каждой компании;
7. [x] **метод get_all_vacancies** отвечает за получение списка всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию;
8. [x] **метод get_avg_salary** отвечает за получение средней зарплаты по вакансиям;
9. [x] **метод get_vacancies_with_higher_salary** отвечает за получение списка всех вакансий, у которых зарплата выше средней по всем вакансиям;
10. [x] **метод get_vacancies_with_keyword** отвечает за получение списка всех вакансий, в названии которых содержатся переданные в метод слова.



В программе реализована функция для взаимодействия с пользователем. 
Функция взаимодействует с пользователем через консоль. 
Возможности этой функции следующие:
-выбор региона из предложенных для получения топ-10 работодателей по количеству открытых вакансий на hh.ru
(Чита, Иркутск, Улан-Удэ, Владивосток, Новосибирск);
-загрузка вакансий полученных работодателей;
-выбор пункта меню:
```
Для получения:
- списка всех компаний и количества вакансий у каждой компании 
введите 1;
- списка всех вакансий с указанием названия компании, названия вакансии, зарплаты и ссылки на вакансию 
введите 2;
- средней зарплаты по вакансиям
введите 3;
- списка всех вакансий, у которых зарплата выше средней по всем вакансиям
введите 4;
- списка всех вакансий, в названии которых содержатся переданные слова
введите 5.
Для завершения работы введите 0.
```
