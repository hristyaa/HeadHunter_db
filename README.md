# Приложение для получения информации о работодателях и вакансиях с платформы hh.ru.

## Описание:

Программа получает данные о работодателях и их вакансиях с сайта hh.ru, сохраняет их в JSON-файлы и проектирует таблицы в БД PostgreSQL для хранения полученных данных.

## Установка:

Клонируйте репозиторий:
```
https://github.com/hristyaa/HeadHunter_db.git
```

## Запуск:

```
python main.py
```

## Функциональные возможности:
Функциональный код разбит на модули: модуль для взаимодействия с API, модуль для создания базы данных, модуль для взаимодействия с базой данных.
1. **Модуль для взаимодействия с API - hh_api.py**.
Реализованы следующие методы:
- **метод get_company** отвечает за получение данных о топ-10 компаниях с наибольшим количеством вакансий (по умолчанию в Чите)
и сохранение данных в JSON-файл "../data/company.json" (по умолчанию);
- **метод get_employers_id** отвечает за получение списка employers_id (id работодателей);
- **метод insert_employers_from_json** отвечает за загрузку данных по API-запросу о работодателях в таблицу employers;
- **метод get_vacancy** отвечает за получение данных о вакансиях топ-10 работодателей и сохранение данных в JSON-файл "../data/vacancy.json" (по умолчанию);
- **метод insert_vacancies_from_json** отвечает за загрузку данных по API-запросу о вакансиях в таблицу vacancies.
2. **Модуль для создания базы данных - hh_database.py**.
Реализованы следующие методы:
- **метод create_database** создает базу данных;
- **метод create_tables** создает SQL-таблицы "employers" и "vacancies";
- **метод clear_table** очищает данные в таблицы.
3. **Модуль для с базой данных - db_manager.py**
Создан класс DBManager для работы с базой данных (таблицами employers и vacancies).
В классе реализованы следующие методы:
- **метод connect** отвечает за установку соединения с базой данных;
- **метод get_companies_and_vacancies_count** отвечает за получения списка всех компаний и количества вакансий у каждой компании;
- **метод get_all_vacancies** отвечает за получение списка всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию;
- **метод get_avg_salary** отвечает за получение средней зарплаты по вакансиям;
- **метод get_vacancies_with_higher_salary** отвечает за получение списка всех вакансий, у которых зарплата выше средней по всем вакансиям;
- **метод get_vacancies_with_keyword** отвечает за получение списка всех вакансий, в названии которых содержатся переданные в метод слова;
- **метод close** отвечает за закрытие соединения.

В программе реализована функция для взаимодействия с пользователем. 
Функция взаимодействует с пользователем через консоль. 
Возможности этой функции следующие:
-выбор региона из предложенных для получения топ-10 работодателей по количеству открытых вакансий на hh.ru
(Чита, Иркутск, Улан-Удэ, Владивосток, Новосибирск);
-загрузка вакансий полученных работодателей;
-выбор пункта меню:
```
Для получения:
- списка всех компаний и количества вакансий у каждой компании 
введите 1;
- списка всех вакансий с указанием названия компании, названия вакансии, зарплаты и ссылки на вакансию 
введите 2;
- средней зарплаты по вакансиям
введите 3;
- списка всех вакансий, у которых зарплата выше средней по всем вакансиям
введите 4;
- списка всех вакансий, в названии которых содержатся переданные слова
введите 5.
Для завершения работы введите 0.
```
